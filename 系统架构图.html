变量名说明示例

OPENAI_API_KEYLLM API Key（不设则用内置模板兜底）c34d...kzdj

OPENAI_MODEL模型名称glm-4-flash

ATOM_DISABLE_AUTH设为 1 开启免登录访客模式1
ATOM_PUBLIC_URL站点公开访问基础 URLhttps://atom.example.com

🛠 技术栈

层级技术
前端React 18 · React Router · Vite · 原生 CSS（无 UI 框架依赖）
后端Python 3.11+ · FastAPI · SQLAlchemy 2.0 · httpx（异步 HTTP）
认证Argon2 密码哈希 · HttpOnly Cookie Session（30 天滑动续期）
数据库Neon Postgres（线上）/ SQLite（本地）
存储Vercel Blob（对象存储）→ Postgres SiteFile（回退）→ 本地文件
AIOpenAI 兼容协议流式 SSE（GLM-4-Flash 等）
部署Vercel Serverless（vercel.json 路由重写）
